Application Layer

Attack: Fake login page (Phishing)
Presentation Layer
Data is encrypted (HTTPS)
Attack: SSL stripping
Session Layer
Keeps you logged in
Attack: Session hijacking
Transport Layer
Uses TCP to send data
Attack: Port scanning / SYN flood
Network Layer
Uses IP address
Attack: IP spoofing
Data Link Layer
Uses Mac address
Attack: Mac Spoofing
